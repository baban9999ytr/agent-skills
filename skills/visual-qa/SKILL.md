# Visual QA

Capture or inspect the rendered UI at representative narrow and wide viewports. Compare hierarchy, alignment, overflow, interaction states, focus visibility, contrast, empty/loading/error states, and keyboard use. Report evidence-backed findings by severity; do not modify product code merely to create a test fixture.

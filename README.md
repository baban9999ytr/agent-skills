# Agent Skills

Portable, original Agent Skills for compatible coding agents. Skills use `SKILL.md` frontmatter and progressive references; they contain no vendor-specific installation command.

## Included skills

- Apple Design Expert — accessible, polished, platform-aware UI guidance.
- Visual QA — evidence-led responsive and visual review.
- Supabase Architect — schema, RLS, migrations, and performance boundaries.
- Laravel Vue Expert — maintainable full-stack patterns.
- Systematic Debugger — reproduce, isolate, and verify.
- Security Auditor — trust-boundary and supply-chain review.
- Production Readiness — safe release and operations assessment.
